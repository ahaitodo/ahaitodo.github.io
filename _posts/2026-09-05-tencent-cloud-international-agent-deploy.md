## 二、Agent 部署三件套：WorkBuddy + TokenHub + COS 向量桶

这次活动真正的重头戏是给 Agent 开发者的组合拳，页面的原话是：**WorkBuddy Workbench + TokenHub Model + COS Vector Bucket to Reduce Costs, Quick Agent Deployment** 。拆开看：

  * **WorkBuddy（全新上线）：** AI 工作台/工作坊产品，促销价 $14.17/月（原价 $22.14/月），还有 $9.95/月（$119.40/年）的档位，自带丰富的技能与连接器、个性化记忆能力；企业按席位 $40/席/月，带统一席位管理和效率看板。

  * **TokenHub：** 模型 Token 服务，**当前免费试用** ，页面上可以直接体验 Hy4 Preview、GLM 5.3 等模型——相当于模型调用层有人兜底。

  * **COS 向量桶（Vector Bucket）：** 给 AI 应用放向量数据的对象存储方案，官方说法是 "Saves Tokens"——检索层自己做扎实了，每次请求喂给模型的 token 就少，账单直接下来。




这三件套的含义是：以前你要自己找向量库、自己接模型 API、自己搭工作流编排，现在国际站把它们打包成了"开箱即用"的组合。对想把 Agent 产品快速推向海外市场的独立开发者来说，省的是好几周的搭建时间。

## 四、下单前要注意的四件事

  1. **账号体系独立：** 国际站和国内站（cloud.tencent.com）是两套独立账号，注册、实名、支付都不互通，做海外业务建议直接注册国际站。

  2. **支付方式：** 国际站走国际信用卡等海外支付方式，境内读者记得准备好对应卡片。

  3. **节点选择：** 面向欧美用户选硅谷/弗吉尼亚/法兰克福，面向东南亚选新加坡/雅加达；如果主要用户在国内、业务在海外，要权衡链路延迟。

  4. **合规自查：** 海外节点免去了国内备案流程，但目标市场当地的数据合规（如 GDPR）要自己把关，别裸奔。




## 常见问题

### $1.68/月 的轻量配置够跑 AI Agent 吗？

如果你的 Agent 架构是"后端逻辑 + 调用 TokenHub/模型 API"，2核4G 完全够用；要本地跑大模型推理的，看 GPU 实例或 HAI，那是另一种预算。

### WorkBuddy 免费吗？

WorkBuddy 是新上线产品，促销期 $14.17/月（原价 $22.14），另有 $9.95/月年付档；TokenHub 当前提供免费试用。建议先用免费试用跑通流程，再决定付费档位，页面价格以实时显示为准。

### 国际站的价格是含税吗？

国际站以美元计价，账单税费取决于你的账单地址所在地区税务政策，结算页面会自动计算，下单前看一眼总价即可。

### 国内用户能注册国际站吗？

可以注册（用国际邮箱和对应支付方式），但如果你的用户都在国内，还是国内站更合适——延迟和支付都更顺。国际站的定位就是"业务在海外"。
